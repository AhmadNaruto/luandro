# PHASE 4 — Binding Infrastructure

Goal

Implement the common binding infrastructure.

Do not implement LexSoup, Regex, QuickJS or Luau.

Implement

JNI Framework

- String conversion
- Array conversion
- Handle conversion
- Exception conversion

Luau Binding Framework

- userdata
- metatables
- object registration
- lifetime management
- automatic destruction

Deliverables

Reusable JNI framework

Reusable Luau binding framework

Success Criteria

All future engines can use the same infrastructure.
