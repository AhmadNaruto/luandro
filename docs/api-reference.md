# Luandro NRP — API Reference & Sitemap

Welcome to the **Luandro Native Runtime Platform (NRP)** API Reference. NRP provides high-performance, single-process embedded execution engines for **LexSoup** (HTML parsing), **Regex** (JavaScript RegExp), **QuickJS-NG** (JavaScript), and **Luau** (Luau VM).

---

## 📚 Documentation Index

### 1. Kotlin API Documentation (Dokka)
The Kotlin API HTML site is generated using **Dokka** and hosted locally at:
- **Location:** [`library/build/dokka/html/index.html`](file:///data/data/com.termux/files/home/luandro/library/build/dokka/html/index.html)
- **Task command:** `./gradlew :library:dokkaHtml`

```bash
./gradlew :library:dokkaHtml
```
